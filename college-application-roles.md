# College Application Roles

Who does what on Maya's applications, agreed 2026-04-06 when the Project started and confirmed 2026-10-11. Written so nobody assumes someone else did it.

| Task | Owner | Notes |
|---|---|---|
| College list, essays, application forms | Maya | Her account; we do not read essays unless asked |
| Teacher letter requests | Maya | Through the school portal ([[recommendation-letter-requests-2026]]) |
| Transcript, school report, counselor letter | [[janelle-forbes]] | Ten school days' notice |
| Application fees | Renata | Card in Bitwarden; receipts to Paperless-ngx |
| National student aid form | Renata | With Maya; tax figures from Nathan ([[student-aid-form-checklist]]) |
| College-specific aid forms | Renata | Deadlines in [[maya-college-list]] |
| Net price calculators, cost table | Nathan | [[college-cost-comparison]] |
| Calendar reminders | Nathan | Seven days before each deadline on the [[family-calendar]] |
| Campus visits, driving | Nathan | [[college-visits-2026-06-22]] |

Each submission follows [[submit-a-college-application]].
