# Quillan Remodeling Bid 2025-12

## Summary

Fixed-price bid from Quillan Remodeling for the kitchen and hall bathroom, received 2025-12-17, two days before the deadline. Base $67,200, plus option C (curbless shower package) at $4,200: $71,400. This became the contract.

## Key Details

- Kitchen $46,900, hall bathroom $20,300, curbless option $4,200. Permit and inspections included.
- Allowances only for tile ($1,800) and light fixtures ($600); everything else specified by model from Dana's drawings.
- Named subcontractors: [[sione-tupou]] (tile), an electrician to be confirmed (later [[lena-marsh]]), a plumbing firm.
- Start 2026-03-02 with the bathroom; kitchen from 2026-06-15 so cabinets could arrive first.
- Payment: 10% deposit, stage payments, 10% retention to final inspection.
- Exclusions: appliances (owner-supplied), anything behind walls not visible at bid time, which is where both change orders came from.

The winning bid. See [[renovation-bid-comparison-2026-01-12]] and [[quillan-remodeling-contract]].
