# Renovation Lessons So Far

Draft, written 2026-10-18 the day the temporary kitchen came down. Will be finished after the final inspection and used for the roof.

1. Budget 15% contingency in a house this age, as its own line ([[renovation-contingency]]).
2. Read the old inspection report before signing. The soft floor was flagged in 2011 ([[house-purchase-inspection-2011]]).
3. Do the load calculation before the contract if anything big and electric is added ([[kitchen-electrical-load-calculation]]).
4. Ask suppliers for a production slot, not a delivery estimate ([[cabinet-delivery-slip-2026-07-20]]).
5. Photograph every open wall with a tape measure in frame ([[renovation-photo-log]]).
6. Normalize bids before comparing ([[pick-the-contractor-not-the-lowest-bid]]).
7. The temporary kitchen is a project of its own; give it a budget and a plan ([[temporary-kitchen-setup]]).
8. Weekly 15-minute site check, decisions confirmed by email the same day. This avoided every argument we might have had with Hector.

What went right: the bathroom, on time and as designed; no disputes; inspections first time.
